## Remediation implementation

The subsequent fix branch addresses STD-1/STD-2 with shared conditional JSON writes and non-reusable references; SPEC-1/2/3 with canonical account and portal collections plus legacy imports; SPEC-4 with durable-record aggregation; and SPEC-5 with status-enforced verification.
